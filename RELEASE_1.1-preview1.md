# SplatTricia 1.1 preview

Historical test build introducing optional 16-bit depth maps and wiggle animations as MP4, GIF and PNG frame sequences.

For normal use, download the [stable SplatTricia 1.1 release](https://github.com/muelli1975/SplatTricia/releases/tag/v1.1).

## Installation

Windows and a compatible NVIDIA graphics card are required. Download all three ZIP files and extract them into the same destination, merging their `SplatTricia` folders. Keep this preview separate from a stable installation.

Obtain `sharp_2572gikvuh.pt` from [Apple's official SHARP project](https://github.com/apple-aiml-research/ml-sharp), read and accept Apple's model terms before downloading, and place the file in `SplatTricia/models`. The checkpoint is not included.
